# 粵語升級器（網頁版）

手機／電腦打開就能練的粵語口語訓練器，純靜態（HTML + CSS + 原生 JS），不需要伺服器、不需要建置。

## 使用方法

打開網站後：

- **① 聲調** 粵拼調號 ↔ 實際音高的配對（L2 最主要的缺口）
- **② 音素** 最小對比對（三／心、街／雞、我／澳……）
- **③ 主動提取** 看中文，出聲講粵語，再揭曉答案自評
- **④⑤ 用詞・詞彙** 港式詞替換表 + 295 條分場景詞庫
- **⑥ 講嘢** 跟讀句、語氣詞選擇題、情境對話（可錄音回放比對）、語氣詞表、港味習慣

發音用系統內建的粵語語音（iOS 粵語／Android Google 粵語），所以不需要任何音檔。
在 **https 網址**下（就是本站），手機的 🎙 錄音比對 可以正常用。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 外殼（分頁、設定抽屜） |
| `style.css` | 樣式（含手機版斷點） |
| `data.js` | 題庫：聲調、最小對比、主動提取、語用、俚語、懶音 |
| `lexicon.js` | 詞庫：295 條分場景港式詞 + 詞替換表 |
| `speak.js` | 口語層：跟讀句、語氣詞題、情境對話、港味習慣 |
| `app.js` | 全部邏輯（路由、抽題、間隔重複權重、TTS、錄音） |

改內容只要改 `data.js` / `lexicon.js` / `speak.js` 三個檔案，重新整理即生效。

## 粵拼校對

本專案全部粵拼已用 rime-cantonese 字表（26982 個單字）做全量機器校對：1457 個可比對音節中 1415 個（97.1%）完全一致，其餘 42 個逐條看過（差異集中在詞層變調與語氣詞固定調）。
