设置

没有粤语语音怎么办？

Windows：设置 → 时间和语言 → 语言和区域 → 中文(繁体，香港特别行政区) → 语言选项 → 语音 → 安装。 装完刷新本页。装不了也能用：所有题目都有粤拼，只是没有声音。

AI 陪練點用？點解要 key？

本頁係純靜態網頁、冇後端，所以 AI 由你部機嘅瀏覽器直接叫 DeepSeek（api.deepseek.com）。 去 platform.deepseek.com 註冊、充 ¥10、建一個 API key，貼上上面個格就得。 key 淨係存喺你本機 localStorage，唔會上傳去任何作者伺服器（都冇作者伺服器）。
